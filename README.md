# Telegram-бот: Пользовательское мнение по Dota 2 и CS2

Бот показывает в реальном времени, **что люди выбирают чаще** на матчах Dota 2 и Counter-Strike 2 (проценты П1/П2, тоталы, форы и т.д.) — точно как блок «Пользовательское мнение» на stavka.tv.

## Что умеет

- Кнопки выбора дисциплины: **Dota 2** / **CS2**
- Список ближайших матчей
- По нажатию на матч — красивый блок с процентами и прогресс-барами:
  - Победитель матча
  - Тотал (ТМ/ТБ)
  - Форы
  - Точный счёт
- Кнопка «Обновить»
- Данные берутся напрямую с публичного API stavka.tv

## Быстрый старт

### 1. Создай бота
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и юзернейм
4. Скопируй **токен** (выглядит как `7123456789:AAH...`)

### 2. Установка (на компьютере / сервере)

```bash
# Клонируй или скачай файлы
pip install -r requirements.txt

# Запусти
export BOT_TOKEN="твой_токен_сюда"
python bot.py
```

Или создай файл `.env`:
```
BOT_TOKEN=твой_токен_сюда
```

И в коде уже стоит `os.getenv("BOT_TOKEN")`.

### 3. Бесплатный хостинг (рекомендуется, т.к. у тебя только iPhone)

#### Вариант A — Railway (самый простой)
1. Зайди на [railway.app](https://railway.app) → войди через GitHub
2. New Project → Empty Project
3. Добавь сервис → Deploy from local / GitHub
4. Загрузи файлы `bot.py` и `requirements.txt`
5. Variables → добавь `BOT_TOKEN` = твой токен
6. Deploy

Бот будет работать 24/7.

#### Вариант B — Render.com
1. [render.com](https://render.com) → New → Web Service
2. Подключи GitHub-репозиторий с этими файлами
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Environment → `BOT_TOKEN`

#### Вариант C — PythonAnywhere
1. Зарегистрируйся на [pythonanywhere.com](https://www.pythonanywhere.com)
2. Загрузи файлы
3. В консоли: `pip install --user aiogram aiohttp`
4. Запусти через Always-on task или bash-консоль

## Важно

- Бот использует **неофициальный** публичный API stavka.tv. Он может измениться.
- Не злоупотребляй частотой запросов.
- Данные обновляются в реальном времени — чем больше людей сделали прогноз, тем точнее проценты.

## Команды бота

- `/start` — главное меню
- `/help` — справка
